# Ultrasound Datasets

This folder is intended to store the multi-view ultrasound RF data and the ground truth speed of sound maps. 

Due to file size limits on GitHub, the raw `.mat` and `.h5` files are not hosted in this repository.

## How to use
To run the code, download the datasets and place them in the corresponding folders:
- `dataset/anechoic_cyst/`
- `dataset/two_layers/`
